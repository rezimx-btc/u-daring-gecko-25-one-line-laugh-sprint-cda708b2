# One-Line Laugh Sprint

A single original one-liner: a light, funny take on everyday life, written
fresh for the One-Line Laugh Sprint bounty. The line is the whole entry —
one sentence about the universal habit of opening the fridge hoping the
leftovers have somehow improved themselves since last time.

> I opened the fridge twice in five minutes, as if the leftovers had secretly cooked themselves a promotion.

## How to run

```sh
python3 main.py
```

This writes the line (plus a trailing newline) to `/output/entry.txt`.
Stdlib only — no dependencies, no network.
